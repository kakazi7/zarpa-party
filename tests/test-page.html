Zarpa Party test page

  1. Serve this folder over HTTP, e.g. npx http-server tests -p 8080, and open http://localhost:8080/test-page.html in two Chrome windows (or two profiles).
  2. Click the extension icon, then Enable on this site and accept the permission prompt.
  3. Window 1: Create Party (the invite link is copied). Window 2: paste the link in the address bar.
  4. Play, pause, seek and change the speed in either window; the other must follow. Try the chat, reactions, fullscreen and the shortcut.
